# F14 — Consolidação, Linux, distribuição e pedagogia

> **Estado:** PLANEJADA · **Fonte canônica:** [Especificação integral](../../docs/specs/ESPECIFICACAO-COMPLETA-v1.md) · **Gate:** avanço somente com evidência reproduzível e revisão humana.

**Marco:** M5 · **Ordem de execução:** 16º de 16 (F14)

## Escopo e critérios de aceite


**Objetivo:** aplicativo doméstico estável, documentado e utilizável de ponta a ponta.

**Bibliotecas:** integração final, packaging compatível e testes de regressão. Python empacotado **separadamente/opcional**; dependência ML não deve inflar/impedir o instalador básico. Lua segue opcional.

**Experimentos:** instalação limpa do `.deb` no cerebro (Kubuntu), dispositivo REAL, troca de áudio, atualizações, caminho de dados, backups, migrações SQLite, workflow da lição Golden importada pelo usuário, X11/Wayland do KDE, uso de aula com vídeo e IA.

**Entregáveis:** pacote `.deb` de distribuição, manual PT-BR, guia A4 simples para conectar REVAS, tutorial “primeiros 10 minutos”, vídeo demonstrativo, notas de versão, lista SBOM/licenças, relatório de homologação.

**Aceite F14:**

- [ ] Instalar o `.deb` em instalação limpa do Linux (Kubuntu, cerebro) sem ferramentas de desenvolvimento (ADR-0004); abrir e usar MIDI+SF2 **sem Python** instalado.
- [ ] Passar teste ponta a ponta: REVAS conectado → tecla iluminada → som escolhido → exercício → MIDI gravado → partitura carregada → metrônomo → prática → progresso persistido.
- [ ] Passar fluxo IA sob demanda: vídeo autorizado → rascunho → revisão → lição → prática e avaliação; sem travamento do desktop.
- [ ] 60 min de sessão real sem crash, notas presas persistentes, underrun de áudio inaceitável ou corrupção de arquivo; relatório dos eventos e recursos.
- [ ] Migrações preservam dados e rollback/backup por versão é demonstrado em cópias de teste.
- [ ] Presença de modelos não comerciais é sinalizada e distribuição respeita suas licenças; *sem upload* sem autorização.
- [ ] Linux (Kubuntu, cerebro) é a única plataforma da v1 (ADR-0004); suporte declarado só com evidência de teste, não por simples compilação. Windows fora do escopo.
- [ ] Gate de hardware: NÃO VERIFICADO bloqueia (ADR-0006).
- [ ] Checklist geral assinado; pendências de menor severidade catalogadas; sem bugs críticos.
